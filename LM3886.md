power output = 40 watts
load resistance = 4 ohms

Output voltage Peak = sqrt(2 * power output * load resistance) = sqrt(2 * 40 watts * 4 ohms) = sqrt(320) = 17.89 volts

Output Current Peak = sqrt(2 * power output / load resistance) = sqrt(2 * 40 watts / 4 ohms) = sqrt(20) = 4.47 amps

Max supply voltage = +-(Output voltage peak + 4 volts)*(1 + 0.15) * (1.1) = +-(17.89 + 4)*(1 + 0.15) * (1.1) = +- 25.6 volts

the input sensitivity and output power determines the voltage gain required.

voltage gain >= sqrt(ouput power * load resistance) / voltage input = sqrt(40 watts * 4 ohms) / 1 volt = 12.65 V/V  = approx = 13

Now calculating the input resistance of non inverting amplifier configuration when Rf is set at 100k ohms

input ressitance = Rf / (voltage gain - 1) = 100k ohms / (13 - 1) = 8.33k ohms approx = 8.2k ohms

The bandwidth requirement must be stated as a pole, i.e., the 3 dB frequency. Five times away from a pole gives
0.17 dB down, which is better than the required 0.25 dB.
    fl = 20 Hz / 5 = 4 Hz
    fh = 20 kHz * 5 = 100 kHz

At this point, it is a good idea to ensure that the Gain-Bandwidth Product for the part will provide the designed
gain out to the upper 3 dB point of 100 kHz. This is why the minimum GBWP of the LM3886 is important.
GBWP ≥AV × f3 dB = 13 × 100 kHz = 1.3 MHz (13)
GBWP = 2.0 MHz (min) for the LM3886 (14)
Solving for the low frequency roll-off capacitor, Ci, we have
    input capacitance >= 1 / (2π × Rin × fl) = 1 / (2π × 8.2k ohms × 4 Hz) = 4.84 µF approx = 4.7 µF

## Single-supply calculator

Run `python LM3886.py` or import `amplifier_calculations()` and pass the
required output power and speaker resistance:

```python
from LM3886 import amplifier_calculations

values = amplifier_calculations(Pout=40, RL=8, Vin=1.0)
print(values["single_supply_voltage_v"])
```

The calculator reports a single DC supply estimate, a half-supply signal
reference, feedback resistors, and minimum input/output coupling capacitances.
The supply estimate doubles the required output swing because the single-supply
signal is centered around half the rail:

```text
VCC = 2 × (Vout_peak + headroom) × (1 + tolerance) × margin
```

The output capacitor is in series with the speaker. Its calculated minimum
capacitance uses the requested low-frequency cutoff; select an available value
at or above that result. Its voltage rating should be at least the calculated
supply voltage. Bias the LM3886 input around `VCC / 2` and use the single-supply
biasing and AC-coupling topology in the [LM3886 datasheet](./lm3886.pdf); the
calculator does not size that complete bias network.

These are first-pass electrical values, not a guarantee of continuous output
power. Check the datasheet supply limits, power-dissipation curves, heatsink,
speaker impedance, and power-supply current capability for the actual design.
