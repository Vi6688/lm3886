power output = 40 watts
load resistance = 4 ohms

Output voltage Peak = sqrt(2 * power output * load resistance) = sqrt(2 * 40 watts * 4 ohms) = sqrt(320) = 17.89 volts

Output Current Peak = sqrt(2 * power output / load resistance) = sqrt(2 * 40 watts / 4 ohms) = sqrt(20) = 4.47 amps

Max supply voltage = +-(Output voltage peak + 4 volts)*(1 + 0.15) * (1.1) = +-(17.89 + 4)*(1 + 0.15) * (1.1) = +- 25.6 volts

the input sensitivity and output power determines the voltage gain required.

voltage gain >= sqrt(ouput power * load resistance) / voltage input = sqrt(40 watts * 4 ohms) / 1 volt = 12.65 V/V  = approx = 13

Now calculating the input resistance of non inverting amplifier configuration when Rf is set at 100k ohms

input ressitance = Rf / (voltage gain - 1) = 100k ohms / (13 - 1) = 8.33k ohms approx = 8.2k ohms

The bandwidth requirement must be stated as a pole, i.e., the 3 dB frequency. Five times away from a pole gives
0.17 dB down, which is better than the required 0.25 dB.
    fl = 20 Hz / 5 = 4 Hz
    fh = 20 kHz * 5 = 100 kHz

At this point, it is a good idea to ensure that the Gain-Bandwidth Product for the part will provide the designed
gain out to the upper 3 dB point of 100 kHz. This is why the minimum GBWP of the LM3886 is important.
GBWP ≥AV × f3 dB = 13 × 100 kHz = 1.3 MHz (13)
GBWP = 2.0 MHz (min) for the LM3886 (14)
